# h3 Kotitehtävä

## The Apache Software Foundation 2023

Apachen dokumentaatio käsittelee nimipohjaisia virtuaalipalvelimia, jotka mahdollistavat useiden eri verkkosivustojen ylläpitämisen yhdessä ja samassa IP-osoitteessa. 
Tämä on nykyään suositeltu tapa, sillä se säästää IP osoitteita ja on joustava; palvelin tunnistaa oikean sivuston asiakkaan lähettämän HTTP otsakkeen perusteella. 
Jos pyynnölle ei löydy täsmällistä vastinetta asetuksista, Apache tarjoilee automaattisesti konfiguraatiolistauksen ensimmäisen sivuston ns. oletussivuna.

## Karvinen 2018 
Tero Karvisen artikkeli puolestaan opastaa yksityiskohtaisesti, kuinka tämä konfiguraatio tehdään käytännössä Linux ympäristössä.
Uutta sivustoa varten luodaan asetustiedosto /etc/apache2/sites-available/ hakemistoon, johon määritellään vähintään palvelimen nimi ja sivuston tiedostojen sijainti. 
Lopuksi uusi sivusto aktivoidaan a2ensite-komennolla ja Apache käynnistetään uudelleen, minkä jälkeen toimivuuden voi varmistaa esimerkiksi curl komennolla tai muokkaamalla testausta varten /etc/hosts tiedostoa.

## Lokitapahtuman analyysi
<img width="943" height="152" alt="image" src="https://github.com/user-attachments/assets/acec3b3c-d3ee-4836-ac84-56d9e32f20d6" />

- **127.0.0.1** = Pyynnöntekijän ip. (Kiva laittaa tämä tänne :D)
- **- -** = Tunnistetiedot. Ensimmäinen viiva on identd-tieto ja toinen on userid. Koska sivu ei vaadi HTTP-kirjautumista, tässä kohdassa on pelkkä viiva.
- **[27/Jan/2026:16:11:43 +0200]** = Aikaleima
- **GET** = Metodi, eli selaimen tapa hakea tietoa palvelimelta.
- **200** = Statuskoodi
- **3383** = Vastauksen koko. Palvelin lähetti selaimelle 3383 tavua dataa.
- **Mozilla/5.0 ... Firefox/140.0** = User-Agent. Kertoo selaimen ja laitteen tiedot.

Aloitin luomalla sivustolle oman kansion kotihakemistooni (~/publicsites/hattu), jotta voin muokata sivuja jatkossa normaalina käyttäjänä ilman sudo-oikeuksia.
Tämän jälkeen konfiguroin Apachelle uuden asetustiedoston nimeltä hattu.conf. Määrittelin sinne tarvittavat asetukset sekä nimesin ServerName hattu.linux.com:ksi. //Korjaan seuraavalla keralla// 
Lopuksi vaihdoin aktiivisen sivuston: disabloin aiemman kimi.conf sivuston komennolla sudo a2dissite ja enabloin uuden sivuston komennolla sudo a2ensite. 
Latasin asetukset voimaan (systemctl reload apache2).
