# H6 Kotiläksy

## Tiivistelmät
Let's Encrypt: How It Works

- Automaatio: Koko prosessi on automatisoitu ACME protokollalla, mikä poistaa manuaalisen säätämisen tarpeen.
- Domain-varmistus: CA varmistaa hallintaoikeuden sijoittamalla palvelimelle tietyn tiedoston tai DNS-tietueen.
- Lyhytikäisyys: Sertifikaatit ovat voimassa vain 90 päivää, mikä pakottaa automaattiseen uusimiseen ja parantaa tietoturvaa, jos avaimet vuotavat.

Apache SSL/TLS Basic Configuration

- Mod_ssl: Apachen oma moduuli, joka mahdollistaa salauksen (HTTPS).
- Direktiivit: Tärkeimmät asetukset ovat SSLEngine on sekä polut sertifikaatti ja avaintiedostoihin.
- VirtualHost: TLS asetukset määritellään yleensä porttiin 443 sidotun virtuaali isännän sisällä.

Asensin sertifikaatin käyttäen Certbot asiakasohjelmaa. Aloitin asennuksen lataamalla tarvittavan Apache liitännäisen komennolla:
sudo apt install python3-certbot-apache

Tämän jälkeen käynnistin automaattisen asennusprosessin komennolla:
sudo certbot

Ajon aikana ohjelma kysyi, mille domainille sertifikaatti asennetaan. Valitsin kohteeksi kimixx.me.
Asennus onnistui kerralla, mistä kertoi lopputuloste:
"Congratulations! You have successfully enabled https on https://kimixx.me"

Suoritin aluksi SSLLabs-testin, mutta se ei näyttänyt arvosanaa ollenkaan, vaan antoi virheilmoituksen. Kävin myös testaamassa verkkosivun toimivuutta suoraan selaimella HTTPS-yhteyden kautta ja huomasin, ettei sivu latautunut ollenkaan.
Tajusin, että vaikka sertifikaatti oli asennettu onnistuneesti palvelimen sisällä, olin unohtanut avata kriittisen 443-portin julkiseksi. Ilman tätä porttia ulkopuolinen liikenne ei päässyt perille palvelimelle asti.

<img width="812" height="561" alt="image" src="https://github.com/user-attachments/assets/06c147d8-fa32-45ed-8353-9523e644e6f0" />

sudo a2enmod ssl komenolla otin käyttöön Apachen SSL moduulin. Vaikka Certbot tekee paljon automaattisesti, tämä varmistaa, että palvelin ylipäätään osaa käsitellä salattua liikennettä.
Komenolla sudo ss -tulpn | grep :443 varmistin, että Apache todella "kuuntelee" porttia 443.
Apache Full avaa kerralla sekä portin 80 että portin 443 palvelimen omasta palomuurista.
